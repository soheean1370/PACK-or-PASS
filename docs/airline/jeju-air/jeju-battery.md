# 제주항공 - 배터리 규정

## 문서 개요
이 문서는 제주항공 공식 홈페이지에 게시된 보조배터리·교체용배터리·리튬배터리 반입 규정을 정리한다. 2026년 4월 20일부로 대한민국 국적 항공사 전체에 공통 적용되는 강화된 개수 제한이 반영되어 있다.

## 기준

### 보조배터리(파워뱅크)
| 기준 | 반입 규정 |
|---|---|
| 160Wh(43,000mAh) 이하 | 휴대 수하물 2개까지 |
| 160Wh(43,000mAh) 초과 | 운송 금지 |

### 교체용배터리(전자기기 예비 배터리)
| 기준 | 반입 규정 |
|---|---|
| 100Wh(27,000mAh) 이하 | 휴대 수하물 5개까지 |
| 160Wh(43,000mAh) 이하 | 휴대 수하물 2개까지 |
| 160Wh(43,000mAh) 초과 | 운송 금지 |

- 보조배터리와 교체용배터리는 위탁수하물로 운송할 수 없으며 반드시 휴대해야 한다.
- 100Wh 초과 160Wh 이하의 보조배터리·교체용배터리는 **합산하여 2개까지만** 기내 반입 가능하며, 반입 시 항공사 승인을 위해 체크인 카운터 방문이 필요하다.
- 기내에서의 사용 및 충전(보조배터리→기기, 기내 전원→보조배터리 모두 포함)은 금지된다. (의료기기 사용 필요 시 등은 예외적으로 사용 가능)

## 제한 조건
- 모든 보조배터리·교체용배터리는 단락 방지 조치(비닐팩 개별 포장, 절연테이프, 단자 보호 캡 등)를 필수로 준비해야 한다.
- 배터리 용량(mAh) 또는 전압(V)이 표시되지 않은 경우 운송이 불가하다.
- 리튬배터리 장착 전동휠(전동보드, 전동킥보드, 세그웨이, 호버보드 등)은 전면 운송 금지된다.
- 리튬배터리 내장 무선고데기는 기내·위탁 모두 운송 불가하며, 배터리 분리가 가능한 경우에 한해 배터리만 분리하여 기내 휴대할 수 있다(160Wh 초과 시 불가).
- 태국 출발 노선은 보조배터리가 32,000mAh를 초과할 경우 운송이 제한된다.
- 팽창되거나 손상된 리튬배터리는 화재 위험으로 기내 반입이 금지된다.

## 예외 사항
- 리튬이온배터리가 포함된 전자장비(핸드폰, 노트북 등)는 160Wh 이하 배터리 장착 시 위탁 또는 휴대 수하물로 총 15개까지 반입 가능하며, 위탁 시 반드시 전원을 꺼야 한다.
- 배터리 분리 가능 전동 휠체어: 300Wh 이하 배터리 기내 반입 가능, 여분 배터리는 160Wh 이하 2개 또는 300Wh 이하 1개까지 반입 가능.
- 배터리 분리 불가 전동 휠체어: 배터리가 견고하게 부착되고 단자에 단락 방지 조치가 되어 있으면 항공사 사전 승인 하에 운송 가능.
- 배터리 분리 가능 스마트 가방: 분리된 배터리는 기내 휴대 가능(160Wh 이하, 단 100Wh 초과 시 항공사 승인 필요).
- 배터리 분리 불가 스마트 가방: 2.7Wh 이하만 기내 반입 가능.

## 확인 필요 사항
- 보조배터리 반입 개수 2개 제한은 2026년 4월 20일부로 시행되었으므로 그 이전 시점의 예외 조치 여부는 확인 불필요(이미 시행 중).
- 100Wh 이하 교체용배터리 5개 한도가 보조배터리에도 동일하게 적용되는지 여부(제주항공은 보조배터리 자체는 100Wh 이하도 160Wh 이하 2개로 통합 표기됨)는 실제 체크인 시 재확인 권장.
