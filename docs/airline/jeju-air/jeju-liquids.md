# 제주항공 - 액체류 반입 규정

## 문서 개요
이 문서는 제주항공 국제선 이용 시 기내(휴대) 수하물에 반입하는 액체·젤·스프레이류의 규정을 정리한다. 대한민국 공항 보안 기준(ICAO 국제 기준 기반)에 근거한다.

## 기준
- 국제선 객실(휴대 수하물) 반입 시, 물·음료·식품·화장품 등 액체·스프레이·젤류로 된 물품은 **100ml 이하의 개별 용기**에 담아, **1인당 1L까지** 허용된다.

## 제한 조건
- 100ml를 초과하는 용기는 잔여량과 무관하게 기내 반입이 불가하다.
- 액체류는 투명 지퍼락 봉투에 담아 1인당 1개로 정리하는 것이 일반적 기준이다.

## 예외 사항
- 공항 면세점에서 구입한 물품 또는 시내 면세점 구매 후 공항에서 전달받은 주류·화장품 등의 액체류는 아래 조건을 모두 충족하면 용량과 관계없이 기내 반입이 가능하다.
  - 면세점 제공 투명 봉인 봉투 또는 국제표준 방식(STEB, Security Tamper Evident Bag)으로 포장
  - 면세품 구입 영수증이 봉인 봉투 안에 동봉 또는 부착
  - 최종 목적지행 항공기 탑승 전까지 미개봉 상태 유지
- 기내 휴대 가능한 면세품 개수(1인당 1개)를 초과하여 다량 구매 시, 탑승구에서 위탁수하물 수수료가 부과될 수 있다.
- 해외 공항에서 환승·통과 시 한국과 다른 보안 규정에 따라 기내 구입 액체류 면세품을 포기하거나 압수당할 수 있어, 사전에 객실승무원에게 알려야 한다.

## 확인 필요 사항
- 국내선의 액체류 반입 완화 적용 여부는 별도 확인 필요.
- 경유지 국가 보안 규정과의 차이는 개별 노선별 확인 필요.
