# 규정 우선순위 정책

## 문서 개요
이 문서는 AI 여행 짐 검사 서비스가 여러 문서(항공사별/국가별/품목별)에서 서로 다르거나 상충하는 정보를 검색했을 때, 어떤 순서로 규정을 적용해야 하는지를 정의한다. 이 문서는 사실적 규정이 아니라 **시스템 내부 판단 로직**을 담은 정책 문서다.

## 기본 원칙

### 1. 법률·정부 규정이 항공사·일반 관행보다 우선한다
세관, 검역, 항공안전당국(FAA, CASA, MLIT, 국토교통부 등)이 정한 규정은 법적 구속력이 있으므로, 개별 항공사 정책이나 품목별 일반 관행(item/ 문서)보다 항상 우선 적용된다.
- 적용 순서: `country/{국가}-*.md` (정부 규정) > `airline/{항공사}-*.md` (항공사 자체 정책) > `item/{품목}-regulations.md` (일반 관행/기본값)

### 2. 더 엄격한(보수적인) 규정을 최종 답으로 채택한다
같은 품목에 대해 출발국·경유국·도착국·항공사 규정이 서로 다를 경우, 항상 **가장 엄격한(제한적인) 기준**을 사용자에게 안내한다. 짐 검사 서비스의 목적은 공항에서의 반입 거부·압수를 예방하는 것이므로, 완화된 규정을 잘못 안내하는 것보다 보수적으로 안내하는 것이 안전하다.
- 예: 보조배터리 개수 제한이 한국 국내 규정은 2개, 특정 도착국 항공사 규정은 3개라면 → 2개 기준으로 안내.

### 3. 시행일(effective_date)이 더 최신인 문서를 우선한다
동일 주제에 대해 여러 버전의 정보가 있을 경우, `effective_date` 또는 `last_verified`가 더 최신인 문서를 우선 채택한다.
- 예: 2026년 4월 20일부로 변경된 한국 항공사 공통 배터리 개수 제한(2개)은 그 이전 정보(100Wh 이하 무제한 등)보다 항상 우선한다.

### 4. 구체성이 높은 문서가 일반 문서보다 우선한다
"대한항공 + 보조배터리"처럼 항공사와 품목이 모두 일치하는 문서가 있다면, "배터리 일반 규정(item/battery/battery-regulations.md)"과 같은 범용 문서보다 우선 적용한다. 범용 문서는 해당 항공사 문서가 없을 때의 **기본값(fallback)**으로만 사용한다.

## 적용 순서 예시 (질의: "제주항공 타고 일본 가는데 보조배터리 3개 가져가도 되나요?")
1. `airline/jeju-air/jeju-battery.md` 확인 (항공사 규정, 160Wh 이하 2개까지) → 1차 기준
2. `country/japan/japan-battery-regulations.md` 확인 (도착국 규정, 모바일 배터리 2개까지) → 2차 대조
3. 두 규정이 모두 "2개"로 일치 → 최종 답변: "2개까지만 가능, 3개는 반입 불가"
4. 만약 두 규정이 불일치할 경우 → 3번 원칙(더 엄격한 기준)을 적용해 최종 답변 생성

## 확인 필요 사항
- 항공사 규정과 국가 규정이 실제로 상충하는 사례가 발견되면, 해당 사례를 `policy/official-check-required.md`에 기록하고 우선순위 판단 근거를 함께 남길 것을 권장한다.
- 이 우선순위 정책 자체는 서비스 운영자의 판단에 따라 조정 가능하며, 법적 자문을 받아 확정하는 것을 권장한다(이 문서는 참고용 초안이며 법률 자문 대체 불가).
