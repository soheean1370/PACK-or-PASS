# 공식 확인 필요 항목 관리 정책

## 문서 개요
이 문서는 이 문서 저장소 내 모든 규정 문서에 부여된 `confidence`(신뢰도) 등급의 의미와, AI 짐 검사 서비스가 사용자에게 답변할 때 이를 어떻게 반영해야 하는지를 정의한다.

## Confidence 등급 정의

| 등급 | 의미 | 서비스 응답 방식 |
|---|---|---|
| high | 공식 정부·항공사 홈페이지 원문을 직접 확인함 | 확정적으로 안내 가능 (단, "정확한 수치는 예약 시점 재확인 권장" 문구는 유지) |
| medium-high | 공식 자료를 기반으로 하되 일부 항목은 2차 자료로 보완함 | 핵심 수치는 안내하되, "확인 필요 사항"에 명시된 항목은 반드시 재확인 문구 포함 |
| medium | 공식 자료가 제한적으로 공개되어 일반 관행·2차 자료에 의존함 | 참고용으로만 안내하고, 반드시 "항공사/정부 공식 확인 필요" 문구를 답변에 포함 |
| low | (현재 저장소에는 없음, 향후 추가 가능) 정보 출처가 불명확하거나 추정 비중이 높음 | 답변에 포함하지 않거나, 매우 강한 경고 문구와 함께만 사용 |

## 서비스 응답 원칙
1. **confidence: medium 이하 문서를 인용할 때는 반드시 "공식 확인 필요" 문구를 사용자 응답에 포함**해야 한다. 짐 검사 서비스가 확정적으로 안내했다가 실제 공항에서 다른 결과가 나오면 사용자 피해로 이어지므로, 불확실성은 숨기지 않고 명시한다.
2. 문서의 `확인 필요 사항` 섹션에 나열된 항목은 답변 생성 시 자동으로 하이라이트하거나, 사용자가 추가 질문 시 우선적으로 노출한다.
3. `effective_date`가 있는 문서(예: 2026년 4월 20일 배터리 규정 변경)는 해당 날짜 이후 정보이며, 사용자가 과거 시점 여행을 문의하는 경우 적용되지 않을 수 있음을 안내한다.
4. `last_verified` 날짜가 6개월 이상 경과한 문서는 재검색(웹 검색 등)을 통해 최신 정보로 갱신하는 것을 권장한다. 항공 규정, 특히 배터리·전자기기 규정은 변경 빈도가 높다.

## 확인 필요 사항 (이 문서 자체에 대한 메타 확인 필요 항목)
- 이 confidence 등급 체계와 재검증 주기는 서비스 운영 정책에 따라 조정이 필요하며, 실제 사용자 피해 방지를 위해 법무 검토를 권장한다.
- 향후 문서가 추가될 때마다 이 목록을 갱신하는 자동화 프로세스(예: YAML frontmatter의 confidence 필드를 스캔하여 medium 이하 문서를 자동 집계)를 구축하는 것을 권장한다.
